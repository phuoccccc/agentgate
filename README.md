# AgentGate

AgentGate is a GenLayer project that will contain an Intelligent Contract, contract tests, and a frontend.

This repository currently contains only the initial project structure. Application code and dependencies will be added in later steps.

## Project structure

- `contracts/` — GenLayer Intelligent Contracts written in Python.
- `tests/direct/` — fast contract tests that can run without GenLayer Studio or Docker.
- `frontend/` — the future user interface.

## Requirements

- Git
- Python 3.12 or newer
- Node.js 18 or newer
- npm

Docker is not required for the current setup. It is only needed if we later choose to run GenLayer Studio locally.

## Current status

Initial repository structure only. No application, contract implementation, tests, or frontend dependencies have been added yet.
